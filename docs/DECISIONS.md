# Decisions

Newest last. Format: date · decision · why · revisit when.

1. 2026-11-07 · No web app, DB or server. Chat (Claude Code) + files is the UI · single user on one laptop, and fewer moving parts · revisit when someone other than the owner needs to use it.
2. 2026-11-07 · Plain `studio.py` orchestrator, no workflow framework · 10 sequential stages don't need Airflow/Prefect · revisit when stages need to run across machines.
3. 2026-11-07 · HyperFrames is the default render engine. Remotion is a second, isolated engine used per template when it looks better · open license, HTML matches the existing kit, Remotion has a richer ecosystem for captions/3D · per template, by test render.
4. 2026-11-07 · Whisper only (faster-whisper on CPU), no ElevenLabs · the user's choice, free · revisit if Telugu accuracy is unacceptable even with script alignment.
5. 2026-11-07 · Scene planning by Claude inside Claude Code (Pro plan), not the API · there is no API key, and planning is validated by the contract either way · switching to the API would change only the plan module.
6. 2026-11-07 · No DepthFlow and no local generative models · the laptop has no NVIDIA GPU (i5-1235U, Iris Xe, 16 GB). Fake parallax via cut-out layers instead · revisit on a GPU machine.
7. 2026-11-07 · All caches on E: · C: has about 12 GB free.
8. 2026-11-07 · HyperFrames uses the installed Chrome. No bundled browser download.
9. 2026-11-07 · Python deps via uv (`uv.lock`), Node via `npm ci` + `package-lock.json`, exact pins · reproducible installs, no surprise upgrades.
10. 2026-11-07 · User media (sample audio, projects, library) is never committed to git · privacy and repo size.
11. 2026-11-07 · Storyboard is HTML screenshotted by headless system Chrome, not Pillow · Pillow wheels on Windows have no raqm, so Telugu conjuncts break; Chrome shapes Telugu and is already required · revisit if Chrome is dropped.
12. 2026-11-07 · Whisper output (`work/whisper.json`) and script alignment (`work/transcript.json`) are separate stages · editing the script must never re-run Whisper.
13. 2026-11-07 · Plan stage stops with exit code 2 and writes `work/plan_brief.md` when `scenes.json` is missing; Claude writes scenes.json in-session, the next run validates it.
14. 2026-11-07 · Text from the script / Gemini JSON, timing from Whisper large-v3 (int8 CPU, default fallback decoding, `condition_on_previous_text=False`), coverage-checked with up to 3 automatic retries; interpolated words flagged `matched=false`; align fails if matched words are more than 8 s apart · Benchmark on the 30 s sample, Gemini text aligned, judged against the cached large-v3 fixture (64 words, 34/67 script words matched, max anchor gap 3 s): small temp=0 (73 s): looped, 0/19 words matched; small temp=0 + Gemini initial_prompt (68 s): looped, 2 garbage words; large-v3-turbo temp=0 (109 s): looped; large-v3-turbo default (129 s): 40 words but no anchor 8.4-24.4 s; large-v3 default (233 s): good in 1 of 2 runs, the other lost 7-30 s (random fallback) -> retry. temperature=0 makes every model loop on Telugu. Gemini timings rejected: two runs on the same audio differed by up to 3.7 s. Model override: env `STUDIO_WHISPER_MODEL` (name or local folder) · revisit when CPU time matters (large-v3 ~ 8x real time here: a 20 min video ~ 2.5 h, unattended, cached) or a GPU is available; next idea is per-VAD-chunk retry instead of whole-file retry.
15. 2026-11-07 · Phase 2 adds no library: Wikimedia/Pexels via stdlib `urllib` (httpx dropped from the plan), thumbnails via ffmpeg, contact sheet via Chrome (Pillow moved to Phase 4) · two GET endpoints and one frame grab don't need dependencies · revisit if downloads need retries/concurrency.
16. 2026-11-07 · Assets are described once by Claude from ONE contact sheet image per batch (not per file), cached by content hash; matching is keyword overlap (local >= 0.34 of query keywords, internet >= 0.5 and >= 2 words); motion_graphic/diagram/chart/text/map scenes without a matching asset are 'template' (Phase 3 renders them), not 'missing'; stock photo/footage try Pexels before Wikimedia, logos/screenshots Wikimedia first · Pro-plan usage (one image read), and the first live run showed Wikimedia returns loose matches (an 1866 newspaper headline for "layoffs headline") · revisit with a local CLIP/vision check if keyword matching picks wrong files.
17. 2026-11-07 · Render v1: one HyperFrames render per scene per format, cache key = scene JSON + asset content hash + template (version + file hash) + brand.json + output size; preview 720p (`draft`), `--final` full size (`standard`); 2 parallel workers with HyperFrames' render lock off (each `--workers 1`); GSAP from the copy HyperFrames ships, no D3 · per-scene renders make a one-scene edit cost one clip; video assets are trimmed/fitted by FFmpeg first because HyperFrames decodes a raw 1080p source slowly (60 s vs 18 s for a 2.3 s 720p clip in the first probe) · revisit when Remotion templates arrive (Phase 4) or render time matters.
18. 2026-11-07 · Preview files are `output/preview_*.mp4`, full size `output/final_*.mp4` · a 720p file must never be mistaken for the upload · revisit never.
19. 2026-11-07 · Charts never invent numbers: bars/count-up come only from `scene.params` (optional field, schema stays v1); without data the chart template shows unlabelled decorative bars.
20. 2026-11-07 · Captions are an overlay inside every scene render (shared studio.js / Remotion studio.jsx), not a separate full-length render or burned-in subtitles · one render per scene keeps the per-scene cache and costs no extra pass; a caption edit re-renders only the scenes whose words changed · revisit if a caption style needs to cross cuts.
21. 2026-11-07 · Music = first file in `_library/music/<brand.music_mood>/`, 18 LU under the narration, sidechain-ducked, 1 s fade-in / 2 s fade-out; SFX = whoosh 0.15 s before cuts into headline/chart (`params.sfx` overrides); loudnorm runs on the final mix · predictable, no extra library, no files = narration only · revisit when the user wants per-project music choice.
22. 2026-11-07 · Parallax: rembg `silueta` (43 MB) on CPU, opt-in per scene, background hole filled with a blur (no inpainting library) · smallest model that cuts a clear subject; isnet-general-use (179 MB) is sharper, switch with `STUDIO_REMBG_MODEL` · revisit if edges look rough.
23. 2026-11-07 · QA gate: previews are always exported (QA printed), `--final` exports only files that pass; placeholder tiles are a warning in previews and a failure in finals · the user must see a preview even with gaps, but a MISSING tile must never reach an upload.
24. 2026-11-07 · Remotion 4.0.541 is the second engine (isolated, system Chrome). Per-template engine choice: `headline` = remotion (test render on 01 scene 11: same look as the HyperFrames version, 11 s vs 13 s for a 3.2 s 9:16 clip; the first render bundles once, ~15 s); every other template = hyperframes. The headline keeps its `index.html`, so going back is one word in template.json · the Remotion licence is free for an individual creator (re-check if the channel becomes a company of more than 3 people) · revisit per template by test render.
25. 2026-11-07 · Raw footage is cut by FFmpeg's scene filter, not PySceneDetect; shots become real files in `assets/shots/` so index, contact sheet, resolve and render need no change · no new library, the user's choice · revisit if slow fades are missed.
26. 2026-11-07 · Maps are offline outlines from Natural Earth (India's point of view on borders), drawn as SVG with an equirectangular projection; no MapLibre, no tiles · works offline forever, no API key or tile terms, Indian audience expects India's official borders; the user's choice · revisit if a scene needs streets or satellite imagery.
27. 2026-11-07 · Screenshots: a `screenshot` template (browser frame) for any image on a screenshot scene, plus automatic capture of `params.url` with an honest headless Chrome (no user-agent spoofing). Sites that block headless browsers (Wikipedia did in the first test) need a manual screenshot dropped as `scene_NNN.png` · the user's choice (both) · revisit never for spoofing.
28. 2026-11-07 · Timeline and map are chosen by `params` on template scenes (`events`, `focus`/`pin`), not new visual types · no contract change (VisualType stays the same), old plans keep working.
29. 2026-11-07 · Contact sheets show at most 20 files per run · a long raw video can make 100+ shots; one readable sheet per run keeps the Pro-plan image cost per read low.
30. 2026-11-07 · Fonts live in `_brand/fonts/<Family>/` and the render loads the brand.json families by @font-face (single-file and variable fonts cover every weight, so no synthetic bold). Default font = Gidugu for Telugu and Latin (the user's pick from a 24-font specimen). `headline` goes back to `"engine": "hyperframes"` (supersedes the engine choice in #24) because the Remotion engine cannot load `_brand/fonts` yet; its Composition.jsx stays and still renders when switched back · one look across every scene · revisit when Remotion gets font loading (pass fonts through the bundle's public folder).
